# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public issues. Report them through [private vulnerability reporting](https://github.com/structured-id/zkpp/security/advisories/new); the report stays confidential until an advisory is published.

Include a description of the issue and its impact, the steps or a proof of concept that reproduce it, and the affected version.

## Supported versions

The latest release receives security fixes.
